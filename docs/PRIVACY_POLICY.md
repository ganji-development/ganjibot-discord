# Privacy Policy

**Last Updated: December 25, 2024**

This Privacy Policy explains how Ganjibot ("the Bot") collects, uses, and protects your information.

## 1. Information We Collect

### 1.1 Automatically Collected Data

When you add the Bot to a server, we may collect:
- **Server Information**: Server ID, name, owner ID, and icon
- **User Information**: User IDs, usernames (for command usage and logging)
- **Message Content**: Only when logging features are enabled by server administrators
- **Voice Activity**: Channel join/leave events when voice logging is enabled

### 1.2 User-Provided Data

- Configuration settings you set through commands or dashboard
- Addon-specific data as configured by server administrators

## 2. How We Use Your Data

We use collected data to:
- Provide and operate Bot features
- Execute commands and logging functions
- Maintain and improve the service
- Store server-specific configurations

## 3. Data Storage

- Data is stored in a secure database
- We retain data only as long as the Bot remains in your server
- Logging data (message edits/deletes) is cached temporarily and not permanently stored unless explicitly configured

## 4. Data Sharing

We do **NOT**:
- Sell your data to third parties
- Share data with advertisers
- Use data for purposes unrelated to Bot functionality

We **MAY** share data:
- If required by law
- To protect our legal rights
- With service providers operating our infrastructure

## 5. Your Rights

You have the right to:
- **Access**: Request a copy of data we store about your server
- **Deletion**: Request deletion of your server's data by removing the Bot
- **Opt-out**: Disable specific logging features via dashboard or commands

## 6. Data Security

We implement reasonable security measures including:
- Encrypted database connections
- Secure authentication for dashboard access
- Regular security updates

However, no system is 100% secure. Use the Bot at your own risk.

## 7. Children's Privacy

The Bot is not intended for users under 13 years of age. We do not knowingly collect data from children.

## 8. Data Retention

- **Configuration data**: Retained until Bot is removed from server
- **Session data**: Expires after 30 days of inactivity
- **Log cache**: Temporary, cleared regularly

Upon Bot removal, server data is deleted within 30 days.

## 9. Changes to This Policy

We may update this Privacy Policy at any time. Significant changes will be announced through our support server.

## 10. Contact

For privacy-related questions or data requests, contact us through:
- Our support Discord server
- GitHub repository issues

*This Privacy Policy is effective as of the date listed above.*
